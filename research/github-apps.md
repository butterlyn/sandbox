### Stack fit
- **Role:** an optional add-on for GitHub-native work (issue → branch/PR, PR review). It cannot carry A1 (no mid-run messaging or approval), A5 or Codex, so a passing stack must get those elsewhere.
- **Preferred topology:** a self-hosted runner in WSL2 on the always-on PC.
  - Run it as a dedicated runner user with a systemd service. It needs a WSL keep-alive, since "systemd services will NOT keep your WSL instance alive" (screen C1).
  - In that user's home: `codex login`, and Claude's `cleanupPeriodDays` raised.
  - Private repos only; set no API-key variables; optionally use `jobs.<id>.container` for per-session images.
- **Security of a runner on a personal PC:**
  - GitHub: self-hosted runners "should almost never be used for public repositories", and on private repos "anyone who can fork the repository and open a pull request … are able to compromise the self-hosted runner environment".
  - The action only runs for users with write access to the repo (`P/`docs/security.md#L5).
  - So: use only private, single-owner repos, keep `allowed_non_write_users` and `allowed_bots` unset, and use a dedicated low-privilege runner user (bug #1688 shows shared-HOME settings leaking across jobs).
  - Sources: https://docs.github.com/en/actions/reference/security/secure-use (undated, retrieved 2026-10-19).
- **Codex → G1 delegation:** a Codex session on the PC can drive G1 with `gh workflow run` / the dispatch API, `gh run watch` and `claude_args: --resume`.
  - That makes the GitHub-run Claude session first-class on the GitHub side (F11a), at the cost of GitHub round-trips and Actions minutes on GH-hosted runners.
  - `gh` is GitHub's official CLI but was not screened (github-repos-issues caveat). The REST API, which is part of GitHub.com, is the screened primitive.
- **Conflicts and limits:**
  - On iPhone, logs show only after a step completes.
  - `display_report` truncates tool results.
  - G2 is unavailable (`@codex` is "Codex Cloud (Legacy)", planned for deprecation), so GitHub-triggered Codex work has no first-party path.
