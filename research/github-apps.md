- **G1 maintenance (N1–N3) passes.**
  - Activity: the latest release, v1.0.253, shipped 2026-10-18, and the default branch has 47 non-bot commits in the last 90 days. 9.6k stars, MIT licence, not archived.
  - N2 passes narrowly. ashwin-ant merged every PR in the window that someone else authored. The second human is mhegazy, who manually dispatched the release run that published v1.0.232 (2026-09-23).
- **G1 uses the Claude subscription (A3), and Anthropic's docs allow it.**
  - Anthropic's docs: `CLAUDE_CODE_OAUTH_TOKEN` "authenticates with your Claude subscription, available on Pro, Max, Team, and Enterprise plans", and "runs use your Claude subscription instead of API billing". `/install-github-app` can mint the token itself.
  - The action installs the unmodified Claude Code 2.1.303 and drives it through the Agent SDK with the `claude_code` preset.
  - Setup rule: never set `anthropic_api_key`. An API key outranks the OAuth token.
  - A3 and A4 are PARTIAL only because G1 runs Claude alone. A Codex partner is structurally required.
- **G1 from the phone (A1) is view and start only.**
  - What works: GitHub Mobile starts runs (`@claude` comment, issue body or title, label, assignee), lists workflow runs and shows completed-step logs. The tracking comment updates as Claude works.
  - Not possible: messaging a running job or answering its prompts. The run is a single headless SDK query.
  - Tool calls are hidden by default. Seeing them needs `show_full_output` (raw JSON in the log) or `display_report` (a step summary that truncates each tool result to 2,997 characters).
- **G1 on the PC (C1)** has two routes. Either GitHub-hosted `ubuntu-latest` runners, or a self-hosted Linux runner inside WSL2 running as a systemd service; Microsoft says systemd "will NOT keep your WSL instance alive". Native Windows runners are undocumented.
- **G2 fails N3(b).**
  - OpenAI's current Cloud environments page: "Codex Cloud (Legacy) continues to support Code Review and the Linear and GitHub integrations. We plan to deprecate this experience."
  - `@codex <task>` "starts a legacy cloud chat". Code review itself is "generally available" and still works today.
  - OpenAI documents no successor for GitHub-triggered `@codex` tasks. Later checks were not run (7.11).
