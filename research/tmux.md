# tmux

- Slug: tmux
- Canonical: https://github.com/tmux/tmux (portable tmux; the OpenBSD base-system tmux is merged into it) · install wiki https://github.com/tmux/tmux/wiki/Installing. The user added it as "cmux for windows/WSL2" (brief 7.18, 7.19; resolve.md D.4).
- Layer(s): runtime/sandbox. tmux is the PC-side session layer: a terminal multiplexer inside WSL2 that keeps the native `claude` and `codex` TUIs alive and attachable. It sandboxes nothing.
- Open source: yes (ISC)
- Latest release checked: 3.8. The tag `3.8` is dated 2026-10-08 and points at commit `7f2a35a`: https://github.com/tmux/tmux/releases/tag/3.8. The release entry is marked "Latest" and says "nicm released this", but its date reads "09 Sep" (see N3). A `release_3.8a` branch was updated on 2026-10-16. `master` HEAD is `c8427d6`, dated 2026-10-19.
- Checked: 2026-10-19 by screen-tmux

  - **Strict alternative:** if only non-merge commits and default-branch PR merges count, no second human qualifies and N2 is FAIL.
- **For 7.4 (generic terminals):**
  - Sessions persist while every client is detached; `destroy-unattached` is off by default.
  - From any SSH terminal, `tmux ls` lists sessions, `tmux attach -t <s>` rejoins one, and `tmux new -d -s <s> -c <dir> claude` (or `codex`) starts one.
  - tmux has no iOS client and no native Windows build. A1 therefore needs a screened iOS SSH/mosh app plus a network path.
- **WSL2 caveat:** tmux sessions last only as long as the WSL2 distro runs.
  - Microsoft documents `instanceIdleTimeout`: default 15000 ms, and `-1` disables auto shutdown. It also says "systemd services will NOT keep your WSL instance alive".
  - Open issue microsoft/WSL#9968 reports distros stopping after the last terminal closes, even with background work running.
  - A keep-alive is therefore a stack setup step. It is untested for tmux specifically.
- **Distro packages lag upstream:** Ubuntu 24.04 LTS ships 3.4, Ubuntu 26.04 LTS ships 3.6a and Debian 13 ships 3.5a, against 3.8 upstream. A source build is the documented alternative.

### Harness integration (from source)
- **How it invokes `claude`:** as the `shell-command` argument of `new-session` (or `new-window` / `split-window`). tmux execs it unmodified in a new pane, with no wrapper, SDK or prompt changes (https://github.com/tmux/tmux/blob/7f2a35ad3321f9ba57a1062ca73b1f3ff26aca53/tmux.1#L1322-L1345).
- **How it invokes `codex`:** the same way.
- **OAuth credentials:** none. tmux never reads, copies or proxies them. The only exposure is environment inheritance (A3 row).
- **Transcripts:**
  - The harnesses' own stores in WSL2: `~/.claude/projects/...jsonl` and `~/.codex/sessions/...`.
  - tmux keeps only in-memory scrollback (`history-limit` 2000).
- **Claude Code agent teams:** split-pane mode puts each teammate (a separate Claude Code instance) in its own tmux pane.
  - "Teammate permission prompts appear in the lead session".
  - The docs cover "Orphaned tmux sessions" (`tmux ls`, `tmux kill-session -t <session-name>`).
  - It is Claude-only and experimental (https://code.claude.com/docs/en/agent-teams, undated).

### Practicalities
- **Environment hygiene:** see the A3 row. Do it before the first `tmux` command after each distro start, since the server inherits that shell's environment.
- **Version lag:**
  - Everything used here is in Ubuntu 24.04's 3.4: `new-session -d -s -c` (and `-e`, added in 3.2), `capture-pane -p`, `send-keys`, user options `@` (2.3), pane formats, `remain-on-exit` and `monitor-silence` (https://github.com/tmux/tmux/blob/7f2a35ad3321f9ba57a1062ca73b1f3ff26aca53/CHANGES#L1450 · https://github.com/tmux/tmux/blob/7f2a35ad3321f9ba57a1062ca73b1f3ff26aca53/CHANGES#L2416).
  - CAO's floor is 3.3+ (lead, cli-agent-orchestrator.md).
  - 3.8 requires a source build (wiki).
- **Related orchestrators:** Gas City (default tmux runtime), CAO (one tmux session per agent) and Claude agent teams (split panes) all build on tmux. Any of them inherits these facts (keep-alive, environment hygiene, the Codex sandbox caveat for agent-issued tmux commands). cmux-tui is an alternative multiplexer for the same layer and is not built on tmux (cmux.md).
