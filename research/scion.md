## Summary
- Screen: FAIL at N2
- **N2 fails.** In the window (2026-04-22 → 2026-10-19), one human, Preston Holmes (GitHub `ptone`, Google), authored 3,461 of the 3,532 human commits (98.0%). He made every push to `main`, so he merged every PR, including those from the 22 other human authors. He also pushed every release tag, and the github-actions bot published the releases. No second human meets any 7.3 PASS condition: the next author has 0.4% of commits, and nobody else merged a PR or triggered a release.
- **Context.** The repo is in the GoogleCloudPlatform org, and other Googlers send PRs (e.g. `ghchinoy`, `zahmedsafeer-hub`), but every merge goes through `ptone`. Workflow comments track work in issues on `ptone/scion`, his personal fork. The repo has no CODEOWNERS or MAINTAINERS file.

The README says Scion is "an actively developed, pre-1.0 project", "evolving rapidly" and "not an officially supported Google product". There is no stable release. The repo has 2.0k stars.
- **Not screened.** C1, A1 and A3/A4 were not screened, because the screen stops at the first hard fail (7.11). Under 7.12, Scion cannot be used in any stack, even as glue.
- **Credential leads (for the record, not verdicts).** On a Workstation, Scion by default copies the host's `~/.claude/.credentials.json` and `~/.codex/auth.json` into every agent container. It can also inject `CLAUDE_CODE_OAUTH_TOKEN`, or scrape a `claude setup-token` token from tmux scrollback and save it as a project secret. Both harnesses are the unmodified npm CLIs, and an API key wins whenever one is set. See Open questions.

## Open questions
- **N2 for an org-hosted repo with one gatekeeper.**
  - 7.3 judges open-source projects on who authors, merges and releases. Under that test the FAIL is clear-cut: one person did all the merging and all the release pushes over six months and about 3,400 merged changes.
  - Against: the repo is owned by the GoogleCloudPlatform org, and at least six `@google.com` authors contributed in the window (Chinoy, Safeer, Vogelbacher, Abbas, `jwith`, `sumeetsing`). If N2 were judged at organisation level (the closed-source test, "≥2 people working on the product"), it could PASS. 7.3 does not allow that test for open-source components.
  - Evidence that would flip N2 to PASS: a second human merging someone else's PR, or pushing a release tag, between 2026-04-22 and 2026-10-19. Neither shows in more than 2,500 main-branch push runs or in the release-run history.
  - Supporting context: workflow comments cite `ptone/scion#2845` and `ptone/scion#3408`. `ptone/scion` is Preston's fork ("forked from GoogleCloudPlatform/scion"), whose Issues tab shows "1k". #3408 was opened and closed by `ptone` on 2026-10-06 and fixed upstream in GoogleCloudPlatform/scion#2599. Planning appears to run through his fork.
