**Credential-handling policy risk (7.16b, required).**
- **Anthropic policy (Legal and compliance, undated, retrieved 2026-10-19).** "Anthropic does not permit third-party developers to offer Claude.ai login into their own applications, or to route requests through Free, Pro, or Max plan credentials on behalf of their users. Moreover, developers may not collect, store, or intermediate Claude.ai credentials or session tokens — sign-in to a Claude account must complete through Anthropic's own flow." The same page says products running Claude Code may not "remove, disable, or restrict any authentication method built into it".
- **Agent SDK overview (undated, retrieved 2026-10-19).** "Unless previously approved, Anthropic does not allow third party developers to offer claude.ai login or rate limits for their products, including agents built on the Claude Agent SDK."
- **What Agor does with Claude credentials:**
  - It collects a user-pasted `claude setup-token` OAuth token, stores it encrypted in its DB, and delivers it to the Agent SDK's bundled Claude Code as `CLAUDE_CODE_OAUTH_TOKEN`.
  - It refuses to use the binary's own `/login` credentials.
  - Optionally (default-on in sandbox and delegated modes), it runs its own claude.ai OAuth. That flow impersonates the Claude Code client (client ID `9d1c250a-e61b-44d9-88ed-5944d1962f5e`, the CLI's paste-back redirect and scope set), holds the refresh token, and hands short-lived access tokens to tasks.
  - It reads `~/.claude/.credentials.json` locally for a "non-secret shape verdict".
  - No user-agent spoofing or usage-endpoint calls were found.
  - Agor's docs admit that provider approval for third-party Claude login has not been established.
- **What Agor does with Codex credentials:**
  - It runs its own ChatGPT device-code flow with Codex's client ID and writes `auth.json`.
  - It accepts a pasted `auth.json` and writes it into the execution home.
  - In `simple` mode, "The login is shared per server user": one ChatGPT login serves every Agor user on that host. For this single-user stack that does not apply.
- **Effect on F1.** F1 is at most PARTIAL for both harnesses: Agor runs SDK-bundled binaries rather than the user's installed CLIs, and the Claude credential is an injected token.
