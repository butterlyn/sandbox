FAVOUR F1–F10 = **15/20**, F11a–e = **10/10**. Orca alone covers A1–A8 for both harnesses. The partners are optional for gates and add F6/F10 points.
- Correction 2026-10-19 (deep-dive): Orca copying Codex `auth.json` into its own `CODEX_HOME` is not the default path. With the system-default account, Orca runs Codex directly on the real `~/.codex` and injects no `CODEX_HOME` (`runtime-home-service-launch.ts` L65). The mirror copy only serves legacy pre-rollout panes and a one-time migration. Managed extra accounts get their own homes.
- N1–N3 pass easily. The repo is active, MIT-licensed and not archived. It shows 96.8k stars. Four humans each wrote ≥10% of commits in the window. v1.4.229 shipped on 2026-10-17, and there were about 7,900 non-bot commits in the last 90 days.
- C1 passes. A native Windows installer ships, and Windows terminals and Codex can run inside WSL. Agent PTYs live in a background daemon that survives quitting the app. The phone, however, connects only while the desktop app (or the headless `orca serve`, which is beta) is running on the PC.
- On function, A1 is met for both Claude Code and Codex. The App Store app lists workspaces and agents, mirrors the live terminal and reads its scrollback. It can reply, answer prompts and approvals, and create a workspace or new tab with a chosen agent. It connects through Orca Relay (vendor-hosted, end-to-end encrypted) or directly over LAN or Tailscale. A1 is held at PARTIAL only because the vendor docs say "The mobile companion is in beta" (section 5: "preview/beta only").
- A3 and A4 pass in the default terminal mode. Orca types the bare `claude` / `codex` command into an interactive shell in a node-pty PTY, and each CLI uses its own login. The experimental Chat UI mode is off by default. It drives Claude through the Claude Agent SDK, which runs the user's installed `claude` with the `claude_code` preset, and Codex through `codex app-server`. Under Anthropic's current Agent SDK note, that Claude path is not a PASS, so the stack should keep Chat UI off.
- Credential caveat: Orca reads OAuth tokens to poll vendor usage endpoints. The Claude token comes from the keychain or `.credentials.json`, and the Codex token from `auth.json`. Orca also copies Codex `auth.json` between `~/.codex` and its own runtime `CODEX_HOME`. This is not an agent loop or proxy, so A3 is unaffected under 7.6, but F1 cannot be PASS. The docs say "No API calls, no extra auth", and the source contradicts this.

### Stack fit
- **Topology on this PC:**
  - The Orca desktop runs natively on Windows and must stay running for the phone. Set `minimizeToTrayOnClose`, which is in source but not documented.
  - Repos on the Windows drive run agents Windows-native; repos on `\\wsl.localhost\…` run them inside WSL2 via `wsl.exe -d`.
  - Agent PTYs live in a daemon that survives quitting the app (documented for Cmd-Q; Windows unconfirmed).
  - The phone reaches the PC through Orca Relay (Orca account, E2EE) or Tailscale direct. `orca serve` (headless) is beta and not needed.
  - Transcripts land in the real `~/.claude` and `~/.codex` of whichever environment runs the agent.
- **Layers covered:** orchestrator plus client/UI, including the native iOS/iPad app, for both harnesses. Alone it covers A1–A8 at component level.
- **Partners:**
  - (1) Networking (Tailscale), to turn F6 into a PASS and to avoid depending on Orca's relay and account.
  - (2) Vendor desktop apps for F10. Claude Desktop sees only Windows-native CLI sessions, so prefer Windows-drive repos for Claude if F10 matters. The Codex app is UNKNOWN.
  - (3) Optional: a transcript viewer (agentsview) or cloud sync for longer-term audit.
- **Conflicts and risks:**
  - The credential side-reads and spoofed user-agents (policy risk, unavoidable).
  - Keep Chat UI / structured mode off: it moves Claude to the Agent SDK path and Codex to app-server.
  - The WSL-versus-Windows split affects F10 and needs Windows-drive mount options that let WSL execute the `orca` CLI.
  - Experimental features (orchestration Runs, Agent Dashboard, Cloud VM) are not counted.
